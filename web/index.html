      Detrending

      Segments

      Every possible segment (a sliding window) of each series is scored against the other complete series — never against other segments — and the best few non-overlapping windows per series join the results. Segments of one series dating at inconsistent lags point to missing or false rings.

      Segment consensus (chronology mode)

      Every chronology-mode run also segments each series in the background, using windows of this length: when two or more well-dated segments agree on a series' placement, that consensus lag is promoted to 1st in the results — badged, with the evidence in the tooltip. With the Segments tool above enabled, consensus reads that run's segments instead (its own length setting).

      Missing / false ring test

      Simulates every possible single-ring correction of one series: each measured ring is split in two (as if a ring boundary was missed inside it) and each neighbouring pair is merged (as if one ring was falsely counted as two). Every edit is re-detrended and fully re-crossdated against the reference — edits that beat the unedited baseline bear fruit. Fruitful corrections can be applied and the test re-run iteratively (each pass hunts the next missing / false ring), and any corrected series can be downloaded as .rwl.

      Build chronology

      Grow a chronology iteratively — crossdate one candidate series at a time against the current mean chronology, review the alignment plots, then approve the suggested lag (or your own override). Uses the current detrend settings and, if a chronology was loaded, seeds from its members.
