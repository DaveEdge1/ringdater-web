Skeleton plot — prototype

Faithful port of dplR skel.plot, adapted as a two-series crossdating overlay (like the heatmap).

Master (narrow rings, pointing down) Sample (narrow rings, pointing up)

Each vertical mark is a ring that is narrower than its immediate neighbours; taller = relatively narrower (scaled 1–10, only ≥3 drawn, per dplR). A convincing crossdate is where the master's downward marks line up vertically with the sample's upward marks. Slide the lag to hunt for that alignment — this is the classic Stokes & Smiley skeleton-plot method that dendrochronologists do by eye.

Algorithm (matches dplR skel.plot)

rw.dt = hanning(rw, filt.weight) (low-frequency curve). For each interior ring i: skel[i] = ( rw[i] − (rw[i−1]+rw[i+1])/2 ) / rw.dt[i]. Keep only negative values (narrower than neighbours), linearly rescale so the narrowest → 10 and the least-narrow → 1, drop values < 3, then ceiling() to integer heights 3–10.
